## 🎯 核心學習目標與技能

1. **Excel 操作介面認知**：Ribbon 功能區、資料工具群組、公式列與名稱方塊、狀態列即時數值檢視。
2. **結構化資料三大黃金原則 (Tidy Data)**：一欄一屬性、一列一紀錄、儲存格絕對不合併。
3. **6 大航運常見髒資料型態處方**：
   - 隱藏空白字元 (`TRIM()`)
   - 欄位複合未原子化 (`資料剖析` / `Ctrl+E 快速填入`)
   - 數值夾帶文字單位 (`SUBSTITUTE()` / `VALUE()`)
   - 日期格式混亂多樣 (`資料剖析 YMD/DMY 秒修`)
   - 港口代碼與大小寫未統一 (`UPPER()` / UN/LOCODE)
   - 重複建檔與鬼影資料 (`條件式格式化` / `移除重複項`)
4. **航運前處理 SOP 六步法**：診斷環境 ➔ 提單去重 ➔ 欄位剖析 ➔ 文字規範 ➔ 轉真數值 ➔ 品質防錯。
